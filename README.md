# SmilePlan

Смета лечения для стоматолога за минуту. Статический сайт (PWA), работает на телефоне и ПК.

Онлайн: https://<ВАШ_ЛОГИН>.github.io/smileplan/

Данные (пациенты, сметы, настройки) хранятся только в браузере пользователя (IndexedDB) —
у каждого посетителя своя пустая копия.

## Локальный запуск
Положите `serve_smileplan.py` рядом с папкой `smileplan/` или запустите из корня репозитория
(сайт ожидает адрес `/smileplan/`):

    python3 serve_smileplan.py 8080
